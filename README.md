# Setúbal Fishy Flow

Queria que criasse animacoes para um um website para colocar como loading e outra para colocar na navbar. A empresa vende chouriços de peixe e é de setubal. Ignora o fundo, tenta brincar com a ancora bolhas e as letras para criar estas 2 animacoes. Também nao queria animacoes muito longas
